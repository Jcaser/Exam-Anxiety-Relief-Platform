# 安心考 · 基于 CBT 的考试焦虑自助干预 Web 应用

> 传智杯全国高校 AI Web 开发挑战赛 · 作品初版（AI 健康与生活服务 — 心理健康对话系统方向）

**一句话**：用认知行为疗法（CBT）把考试焦虑拆开、看清、放下——AI 陪你把慌乱的念头，变成看得清的事实。

---

## 一、赛道与命题背景

- **赛事**：传智杯 · 全国高校 AI Web 开发挑战赛（主题：智启未来 · AI 驱动的 Web 应用创新挑战）
- **归属方向**：推荐选题第 6 条「AI 健康与生活服务 → 心理健康对话系统」
- **核心要求**：AI 须为应用核心而非附属；鼓励 RAG、Agent、多模态、安全可控等深度集成。

## 二、痛点与解决方案

| 维度 | 说明 |
|---|---|
| 真实痛点 | 高校学生高频面临四六级 / 考研 / 期末的**考试焦虑**，但缺乏低门槛、可随时使用的循证自助工具 |
| 现有缺口 | 通用心理咨询门槛高、预约难；泛心理健康 App 缺乏结构化方法与本地隐私保障 |
| 我们的方案 | 以 **CBT 七栏思维记录**为骨架，结合 **RAG 知识库 + AI 对话陪伴 + 进度可视化**，把专业方法变成每天能用的练习 |

## 三、技术架构

```
① 用户与前端层   Next.js 14 (App Router) + Tailwind + 玻璃拟态温暖 UI
② 核心功能模块   焦虑自评 / 智能思维记录 / CBT 对话陪伴 / 进度可视化 / CBT 原典书库
③ AI 能力层      LLM 流式生成（SSE）+ 混合检索（BM25 + 中英对照词表）+ 安全过滤·危机兜底
④ RAG 知识层     四本 CBT 原典全文（71 章 / 4400+ 段切片）+ CBT 结构化知识卡（lib/knowledge.ts）
⑤ 数据层         IndexedDB / localStorage 本地隐私存储（心理数据不出端）
```

- **前端**：Next.js 14、React 18、TypeScript、Tailwind CSS、Framer Motion（动效）、lucide-react（图标）
- **AI 接入**：通过 API Routes 调用兼容 OpenAI 的大模型（DeepSeek / 智谱等），**流式输出（SSE）**；无 Key 时自动降级为本地 RAG 抽取式作答
- **原典书库（RAG 语料底座）**：《理智胜过情感》《Feeling Good》《伯恩斯新情绪疗法》《认知行为疗法：基础与应用》四本 CBT 经典全文入库——
  - `scripts/build_corpus.py`：把原文本清洗 → 按章切分 → 按语义片段（≈420 字、句级重叠）切片，产出 `data/library/corpus.json`
  - `lib/rag.ts`：中文二元词（bigram）+ 英文分词，BM25 打分（k1=1.3, b=0.75），章标题命中加权，内置 50+ 组**中英概念对照词表**（中文提问也能命中英文原版），并带生僻字降噪（规避 OCR 错字进入引用）
  - `/library` 全文检索 + 分章阅读；`/api/library/*` 提供检索/章节接口
- **知识库**：`lib/knowledge.ts` 内置 CBT 循证知识卡（认知扭曲、思维记录、呼吸放松、暴露练习等），与原典检索双路合并后喂给大模型

## 四、AI 技术方案

1. **RAG 检索增强（双路）**：用户提问 → 同时检索「四本原典全文」（BM25 混合检索，取最相关 4 段）与「CBT 知识卡」（关键词匹配，取 2 条）→ 拼接为带编号的上下文 → 大模型按要求引用 `[1][2]` 作答，避免"编造"心理建议。检索层做了章标题加权与每本书限量（保证引用来自多本原典）。
2. **流式输出 + 过程可视化**：`/api/chat` 以 SSE 推送 `trace → citations → delta → done` 事件流。前端实时展示「安全检查 → 原典检索 → 组织回答」的思考轨迹与流式打字效果；回答下方渲染**可点击的原文引用卡**（书名 / 章节 / 摘录），一键跳回书库对应章节。
3. **降级策略**：未配置大模型时走本地抽取式作答——从命中片段中挑选信息量最高、OCR 噪声最少的句子作为摘录，配合分类动作库给出可操作建议；全程无需 API Key 即可完整演示。
4. **安全与可控性**：内置**危机识别关键词**，命中即转介心理援助热线（12356），不给出常规建议；所有回答限定在循证框架、不做医疗诊断。

## 五、创新点

- **选题创新**：聚焦「考试焦虑」这一具体、高频、可量化场景，而非宽泛的心理健康助手。
- **方法创新**：把 CBT 七栏思维记录做成可交互、可追踪的 Web 工具，并用 AI 引导填写。
- **RAG 创新**：四本 CBT 原典全文入库（71 章 / 4400+ 片段），自研轻量混合检索——中文二元词 + BM25 + 章标题加权 + 中英对照词表 + OCR 生僻字降噪，**不依赖任何外部向量库即可部署**；AI 每条建议都带可点击的原文出处，"说的每句话都能翻回书里"。
- **隐私创新**：心理数据默认本地存储，端侧优先，降低用户倾诉门槛。

## 六、安装与运行

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（可选，不配置则使用本地 RAG 抽取式作答）
cp .env.example .env.local
# 填入 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL

# 3. 本地开发
npm run dev          # http://localhost:3000

# 4. 生产构建
npm run build && npm run start
```

> **重建书库语料**（仅在更新原文本时需要）：把四本书的文本放入 `raw/`（文件名见 `scripts/build_corpus.py` 顶部说明），运行 `python scripts/build_corpus.py`，即重新生成 `data/library/corpus.json`。仓库已内置生成好的语料，直接 `npm run dev` 即可使用。
